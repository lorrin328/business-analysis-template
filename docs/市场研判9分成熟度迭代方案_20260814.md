# 市场研判9分成熟度迭代方案

## 一、目标与判定方式

本轮目标不是把主观评分从7.6改写为9，而是建立可复算的10分质量合同。每期报告在发布前由程序从证据、来源覆盖、滚动分析、行动闭环和运行可靠性五个维度计算得分；生产门槛为9.0分。低于9.0分的报告不得覆盖上一期有效报告。

| 维度 | 分值 | 关键门槛 |
|---|---:|---|
| 证据完整性 | 3.0 | 全部来源独立复核、事实锚点匹配、宏观监管A级证据、每个同业模块均有一手证据 |
| 来源权威与覆盖 | 2.0 | 至少12组检索、12项来源、4项官方来源、5个发布主体、5个域名、一手外部来源占比不低于50% |
| 滚动分析质量 | 2.0 | 延续主题有新证据、变化唯一映射、80%以上复核条件可观测、每层2—4个模块 |
| 行动闭环 | 2.0 | 稳定行动键、跨期状态、真实进度、验收指标、31天内明确复核日期 |
| 运行可靠性 | 1.0 | Pro主研究成功、调用可观测；首次通过满分，Flash或Pro修复按级别扣分但不降低事实门禁 |

## 二、基线短板与修订

### 1. 好结果未形成硬门禁

2026年8月14日最新报告中，两个同业模块均已有一手证据，七个延续主题均使用新证据，六项行动与上一期相似度不高；但原程序只检查“同业层至少有一项一手来源”，不能保证每个模块长期维持该标准。

修订后，每个同业模块必须独立具备A/B级一手证据；宏观和监管继续保留A级官方证据门禁。任何单一模块不满足即进入定向修复。

### 2. 来源广度只有数量，没有结构

原门槛为8组查询、8项来源，容易由少数网站重复满足。修订为12组查询、12项来源，并增加官方数量、发布主体、域名和一手来源占比约束。微信公众号仍只使用公开可核验原文，无法访问时如实披露，不用转载或搜索摘要补数。

### 3. 判断字段仍依赖提示词自律

新增程序检查：判断和影响不得引入事实与证据片段中不存在的新数字、日期和政策状态。业务影响可以推演，但不能把推演写成新的外部事实。

### 4. 行动建议缺少跨期台账

每项行动新增`actionKey`、`status`、`previousReportId`、`progress`、`acceptanceMetric`和`nextReviewAt`。相同行动必须复用稳定键；持续行动不得复制上一期进度；“已完成”必须有内部证据；下次复核日期不得超过研究期末后31天。

### 5. 专业度对用户不可见

页面新增研究质量评分区，分别展示五个维度和总分。历史旧报告不伪造评分；从本次新机制生成的报告开始展示。状态文件同时记录最终质量分和模型调用链。

## 三、发布与观察规则

1. 先执行结构和成熟度草稿检查，缺口由Flash定向修复，仍失败升级Pro一次。
2. 再由程序独立访问全部来源并校准标题、日期、摘录和事实字段。
3. 计算质量评分；低于9.0分不发布，保留上一期。
4. 单次生产测试达到9分，只能证明本期结果和机制通过；连续六期首次成功率、评分稳定性和微信公众号可达性仍需观察。
5. 六期观察目标：评分均不低于9.0、外部来源验证通过率100%、首次成稿成功率不低于80%、每个同业模块一手证据覆盖率100%、连续行动均有进度或调整说明。

## 四、仍然保留的边界

- 评分是程序化质量合同，不等于人工合规签审或战略决策批准。
- 微信公众号来源数量不设强制下限，避免为得分绕过访问控制或用转载冒充官方原文。
- 不强制报告制造反转或失效；只有新证据真实支持时才改变历史状态。
- CLI显示的美元成本仅作相对观察，实际费用以DeepSeek账单为准。
