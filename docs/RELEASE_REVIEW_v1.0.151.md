## 根因与修复

2026-09-07的导入同时覆盖2024至2026年人力。生产业绩回读包含130,657条YYYY-MM旧记录和40,270条完整时间戳新记录。默认日期格式推断以首条旧记录为准，丢弃新格式日期，活动人力回填为0。单独查询9月则正常返回79人，复现了合并回算与单月计算的差异。

按本次用户提供原表，2026年9月OTO、证保、蚁桥活动人数分别28、2、49人，月均在职分别296、44.5、63人；合计79/403.5=19.6%。原始明细没有缺失。

解析改为按行识别明确的年在前日期，兼容月份和时间戳混合；数字月份、YYYYMM和YYYYMMDD的整数等值浮点数显式转换，非法小数不截断。新增迁移20260907_mixed_period_normalization，requires_aggregate_rebuild=1。
