# v1.0.126 发布说明：市场研判变化信号确定性归并

## 修复内容

- 市场研判报告的五类变化信号由程序依据当前模块历史状态确定性重建，消除模型生成的重复、跨状态和遗漏映射。
- 失效信号必须对应一个本期 `history.state=expired` 的同主题模块，并引用当前证据解释失效；不再保留没有当前模块的历史失效条目。
- 变化信号映射错误可直接复用6小时内修复检查点完成本地修复，无需再次调用模型。

## 影响范围

- 不改变模型对事实、判断和模块历史状态的业务研判。
- 不改变报告页面、主看板业务口径、SQLite结构、定时周期和凭据配置。
- 失败报告仍不会覆盖上一期有效报告。

## 验收重点

- 每个当前模块必须且只能出现在一条变化信号中，信号类别与模块 `history.state` 一致。
- `expired` 不得包含无当前失效模块的历史残留条目。
- 修复检查点重放不得触发额外模型调用，最终报告须继续通过证据校验与发布门禁。
