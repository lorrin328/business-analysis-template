业务平台趋势的经代销售平台筛选已同步 GitHub 并部署 Ubuntu。运行提交为 `3c69b636892d46cc31908148a1017429b96c2751`；正式入口为 [经营分析看板](https://kpi.bcyt.tech:30443/)。

## 功能与口径

- 勾选经代后显示销售平台复选项，支持全部、清空、单选和多选合计；取消经代后隐藏该行。平台取自源字段“经代机构”，选项合并所选年份及上年，方便按同平台比较。
- 年度展示累计与单月，季度/月度展示所选月份日累计，并保留上年同期；支持期交、规模、折算三种保费口径。
- 平台筛选只改变经代金额，其他业务系列及其机构选择保持原有口径。混合日趋势按完整数据源的共同截止处理，不能把低频平台最后成交日当作经代源截止日。
- 默认全部沿用既有权威经代汇总；拆分为只读查询，不重导 Excel、不重建既有聚合、不修改历史数据。未标注平台、负数冲正和未知年限保留；历史平台明细不足时显示范围限制。
