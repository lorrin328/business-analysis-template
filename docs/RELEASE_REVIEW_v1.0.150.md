## 修复范围

- 完整月替换按源覆盖期间清理长险、交期及相关日级汇总，即使新结果为空也移除旧值；共享表保留未更新的转型或经代分区。

迁移 `20260905_incremental_partition_and_hr_consistency` 标记 `requires_aggregate_rebuild=1`。已有生产库发布使用 `REBUILD_DATABASE=0 REBUILD_AGGREGATES=auto`，从当前 SQLite 原始数据重建汇总，禁止使用旧 Excel 覆盖生产历史。重建前须在一致性备份上演练并核对原始表、目标、账号和历史批次保护情况。
