## 用户可见变化

- 上传区显式选择“完整月替换”或“业绩补充”，预览行数、期间与覆盖范围，再确认写入。改变文件和选项须重新预览。完整月保留原有关键字段要求；补充模式相同记录跳过，差异记录拒绝。
- KPI卡片、详情、AI只读接口和Excel共享指标合同。真实零保留；缺目标、同期、人力或完整覆盖时说明不可计算。活动率同比用百分点，人均按覆盖自然月及月均人力计算。
- 客户事实与原始导入处于同一事务。严格格式编号仅作为候选键，歧义键只精确关联；未确认的客户关系不自动归并。
