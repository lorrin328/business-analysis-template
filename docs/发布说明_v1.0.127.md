# v1.0.127 发布说明：客户指标口径与客户清单导入

本版本在客户分析模块内增加客户清单Excel/CSV导入入口，并形成完整指标口径核对报告。

## 使用入口

- 页面：`/customer-analysis`
- 页签：`数据导入`
- 查看权限：`customer_analysis`
- 正式上传权限：同时需要`upload`

## 导入边界

- 只更新客户—保单关系、承保时间、保单状态和终止原因；不产生业绩金额。
- 先预检、后确认；文件变化后必须重新预检。
- 冲突整批阻断，旧快照保留数据库新值。
- 浏览器按8MB分片上传，后台使用临时SQLite流式归并，不设置固定文件大小、文件数和行数上限。
- 原文件只在受保护临时区保留到预检完成；成功、失败或超过24小时未确认后清理。审计仅保存汇总、文件哈希和操作人。
