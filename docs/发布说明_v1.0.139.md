# v1.0.139 发布说明：星钻显示当前数据并计算达标差额

## 本次解决的问题

星钻页面过去只显示已经生成过结果的月份。生产业绩和人力已经有2026年8月数据，但8月尚未生成星钻批次，因此月份选择仍停在7月，容易误以为数据没有更新。

## 调整内容

- 月份选择同时显示已有历史结果和最新数据月份；8月没有结果时明确标记“待生成”。
- 页面显示统一测算截止日，并分别说明OTO、证保最近出单日。
- 有重算权限的用户可直接生成截至最新数据日的过程结果；查看页面本身不会自动写库。
- 生成后可查看未达标人数、逐人及合计标保差额、还缺的长险件数。
- 当前月份不能选择晚于真实数据的截止日，人力未覆盖目标月份时不能生成。
- 优化星钻原始业绩读取范围，使五百多万行生产库上的当期测算可在可接受时间内完成。

## 发布前验证

- 星钻专项测试：111项通过。
- 全量回归：413项通过。
- 2026年数据质量审计：无问题。
- 使用生产数据隔离副本完成截至2026年8月25日的完整测算，数据库校验正常；未写入生产库。

## 部署说明

本次只更新程序，不重建生产数据库。部署时使用：

```bash
REBUILD_DATABASE=0 sudo bash deploy/deploy.sh
```

部署后由有 `honor_recalculate` 权限的账号进入星钻页面，选择2026年8月并生成截至最新数据日的过程结果，再核对首屏未达标人数与人员追踪明细一致。
