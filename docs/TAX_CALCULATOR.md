# 税优产品测算模块

版本：v1.0.143，2026-08-31新增。实际部署与验收记录见项目工作日志。

## 入口与边界

- 主经营看板顶部“税优测算”进入 `/tax-calculator`；兼容 `/tax-calculator.html`。
- 面向中国居民个人年度综合所得，仅计算税前扣除的当年税额影响；不计算经营所得、非居民所得、单独计税奖金、境外税额抵免、特殊减免或实际退补税。
- 独立静态工具，不含经营数据，页面不要求单独权限；不改变经营API的登录与权限要求。不调用业务接口、不写SQLite、不进行聚合迁移。
- 输入仅保存在页面内存，不上传、不写浏览器存储、不进入URL或日志。刷新即丢失；复制/打印仅由用户主动触发。

## 输入合同

所有金额以元为单位，最多两位小数；缺失不按0处理，明确输入0有效。负数、指数、千位逗号、多余小数和超限值均报错，不静默截断。

| 输入 | 口径 | 边界 |
|---|---|---|
| 年收入 | 工资薪金为年度税前收入；其他综合所得需先换算为税法收入额 | 0至10亿元，工具精度范围并非政策限额 |
| 其他税前扣除 | 三险一金、专项附加及适用的其他扣除合计；不含6万元、个养、税优健康险、预缴税及直接减免税额 | 0至10亿元 |
| 个人养老金扣除 | 按扣除凭证填写已缴或明确假设的可扣除金额，默认0 | 0至12,000元 |
| 税优健康险本年可扣除金额（折叠设置） | 默认2,400元仅为全年足额情景；按实际凭证、资格和有效扣除月份核定后调整，不等同于保费 | 0至2,400元；200元/月，多保单合并限额 |

默认不自动根据保费、生效日期推算本年可扣除金额，以避免年中投保或凭证提交时点造成误算。未取得税优识别码的普通商业保险不得直接填入。劳务报酬和特许权使用费收入额按收入的80%，稿酬按56%计入；模型不自动拆分收入类型。

## 公式与对比

设R为税法口径年度收入额，O为其他扣除，P为个养扣除，H为健康险可扣除额。

- 基准应纳税所得额B = max(0, R - 60000 - O)。
- T(x)按综合所得年度七级超额累进税率计算，或x乘适用税率减速算扣除数；税额四舍五入到分。
- 个养当年节税 = T(B) - T(max(0, B-P))。
- 健康险当年节税（主指标）= T(max(0, B-P)) - T(max(0, B-P-H))。
- 两项合计节税 = T(B) - T(max(0, B-P-H))，等于上述两项之和。
- 四种情景分别为基准、仅个养、仅健康险、两项均扣除。两个“单独购买”节税不能直接相加替代联合情景。
- 内部金额使用整数分；计算税额时使用整数税率与速算扣除分值。纯计算核在 `js/tax-calculator-core.js`，交互在 `js/tax-calculator.js`。

个养领取时另按3%计税，未纳入本次当年税额差。未提供投资收益、未来领取额、费用、贴现与预缴税款，因此不能推导终身净收益或退税额。

## 政策依据

2026-08-31在线核验：

1. [《中华人民共和国个人所得税法》](https://www.chinatax.gov.cn/n810219/n810744/n3752930/n3752974/c3970366/content.html)：年度6万元基本减除费用、综合所得税率表、收入额换算。
2. [财政部 税务总局公告2024年第21号](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5237110/content.html)，2024-12-12：个养年度12,000元据实扣除，领取按3%计税。
3. [财税〔2017〕39号](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/201705/t432115.html)，2017-04-28：健康险2,400元/年、200元/月及按月扣除规则。
4. [国家税务总局征管解读](https://www.chinatax.gov.cn/chinatax/n810341/n810760/c2644729/content.html)：税优识别码与扣除资格。

政策发生变化时，须先复核官方来源、更新计算核及说明，再重跑边界用例。
