# 太平人寿经营分析看板 · 界面优化与美化报告

> 版本：v1（基于当前代码 v1.0.155 审计） · 日期：2026-09-21
> 范围：`经营分析模板.html` 主看板 + 7 个子页面 + `css/tokens.css` + `js/*.js` 中的视图层

---

## 一、结论摘要

**当前界面"地基好、装修乱"。** 主看板已经建立了质量不错的设计令牌体系（`tokens.css`：深色海军蓝三层背景、唯一主色 + 语义色纪律、RGB 透明通道、动效降级媒体查询），方向正确，**不需要推翻重做**。真正的问题在于：

1. **令牌体系只覆盖了主页面** —— 8 个页面里只有 `经营分析模板.html` 引用了 `tokens.css`，其余 7 个子页面各自为政；
2. **硬编码颜色泛滥** —— 全部 HTML 中检出 **248 处**十六进制色值，绕过令牌直接写死；
3. **数据可视化层次不足** —— 达成率类 KPI 只有大数字，没有"目标进度"的视觉表达；密集表格缺少专业数据终端级的排版打磨。

优化策略：**收敛统一（把 7 个子页面并入令牌体系）→ 精修打磨（KPI 进度可视化、数字排版、表格工艺）→ 克制增值（状态指示、加载/空状态、微动效）**。

### 2.2 已有的优点（应保留）

- `tokens.css` 的语义纪律很好：唯一主色 `#4f8cff`、三级文字明度阶梯、语义色（up/warn/down/live）、RGB 通道变量供 `rgba()` 使用、`prefers-reduced-motion` 降级；
- 主看板响应式覆盖完整：宽屏 KPI 9 列 → 常规 3 列 → 移动 2 列，含 iPhone（≤430px）专属适配（底部弹窗、触控目标 ≥36px）；
- KPI 卡片有键盘可达性（`role="button"`、`tabindex`、`:focus-visible`）；
- 上传卡片使用手绘线条 SVG 图标，风格统一、无表情符号。

## 三、美化方向（设计提案）

> 原则：**沿用现有深色数据终端方向做精修，不换肤**。当前令牌色系（深蓝底 + 青蓝主色 + 绿/黄/红语义色）本身就是专业金融终端的经典解法，问题在执行不一致而非方向错误。

### 3.1 统一令牌层（解决 P0）

- 将 `tokens.css` 升级为**全站唯一样式入口**：8 个页面全部引用，删除各子页面私有 `:root` 变量块；
- 扩展令牌语义，补齐当前缺失的组件级令牌：
  - `--accent-subtle`（主色 12% 底，用于选中态）、`--surface-sunken`（比页面底更深的凹陷区，用于表格头/输入框）；
  - 状态点尺寸、进度条高度、图表网格线色等**组件令牌**；
- alias 兼容层保留但加注释标记"弃用"，新代码只允许用新令牌；子页面私有变量（`--blue`→`--accent`、`--gold`→`--warn` 等）做映射替换；
- 248 处硬编码色值分批回收进令牌，主页面 19 处先行。

### 3.2 KPI 卡片：从"数字陈列"到"目标进度仪表"（P1-1，视觉收益最大）

6 张达成率卡片升级为**分段进度条 + 大数字**组合：

- 大数字下方加一条 4px 高分段进度条（实际 vs 目标），进度色随达成区间变化（<60% 红 / 60–90% 黄 / ≥90% 绿），目标线位置刻一个刻度标记；
- 底部元信息保留同比/环比，但对"未配置正式目标"的卡片维持现有虚线框纪律（已有，好设计，保留）；
-  hover 已有 `inset 3px` 左侧色条，保留；增加进度条 0.4s 生长动画（入场时从 0 到实际值），数字做 0.3s 滚动计数——这两个动效成本极低、专业感提升极大。

### 3.3 数字排版系统（P1-2 / P2-3）

- 制定三级数字规范：**看板级**（KPI 大数字 30px/700/tabular-nums）、**表格级**（12px/500/tabular-nums 右对齐）、**标签级**（11px/600/字距 +0.06em）；
- 所有金额、百分比、件数列强制 `font-variant-numeric: tabular-nums`；
- 中文小标签用"加字距 + 降明度"代替加粗变色来建层级（中文无斜体、大写，字距是最安全的层级手段）；
- 百分比统一带符号着色（+绿/-红），与现有 `.up/.down` 对齐。

### 3.4 表格与控制区精修（P1-3 / P1-4）

- 机构维度的 10 个机构 checkbox 改为**两行分组 + "全部/反选"快捷操作**；控制区与图表之间用 1px hairline + 底色微差分区，而不是现在的大边框盒；
- 表格统一：行高 36px 节奏、hover 行底色、数字右对齐等宽、首列 sticky 保持；
- 状态指标从"彩色文字"升级为**前置状态点**（6px 圆点 + 文字），红/黄/绿一目了然且不刺眼；
- 定制 6px 细滚动条（轨道透明、滑块 `--line` 色、hover 加深），全站统一。

### 3.5 告警组件与空/加载状态（P1-5 / P2-1）

- 统一告警条组件：3px 左侧色条 + 语义色 10% 底 + 图标 + 文字 + 右侧操作位，warning/error/info 三级；
- 表格/图表加载统一骨架屏（呼吸灰块），替换"正在加载..."纯文本；
- 空状态统一为"虚线框 + 一句引导文案 + 操作按钮"。

### 3.6 Header 收敛（P2-4）

- 截止日期控件与主导航做视觉分层：导航行为主（大一号、主色态），统计口径行为辅（小一号、次级色）；
- ≤1440px 时"重新计算"收进"管理与工具"菜单，保持单行不折行。

### 3.7 明确不做的事

- 不做玻璃拟态/大面积渐变装饰——与数据终端气质冲突；
- 不引入图标库——现有手绘 SVG 图标风格延续即可；
- 不加 scroll-triggered 入场动画到主内容区——数据看板首屏必须立即可读；
- 不更换字体——中文环境下系统字体栈（PingFang/雅黑）就是最稳选择，仅做字重/字距/字号文章。

## 四、实施路线（建议三期）

| 期 | 内容 | 涉及文件 | 风险 |
|---|---|---|---|
| **第一期：统一** | 子页面全部接入 `tokens.css`；映射替换私有变量；回收主页面 19 处硬编码色值与 10 处内联 style | 7 个子页面 + `tokens.css` + 主页面 | 低。纯 CSS 变量替换，需逐页截图比对 |
| **第二期：精修** | KPI 进度条仪表化；数字排版规范落地；表格/控制区/滚动条/状态点/告警组件 | 主页面 + `kpi-cards.js` + `org-analysis.js` 等 | 中。涉及 JS 渲染片段的 class 调整，需回归 KPI 弹窗 |
| **第三期：增值** | 骨架屏、空状态、进度/计数动效、Header 收敛 | 主页面 + 各模块 JS | 低。增量增强 |

**发布注意（依 AGENTS.md 约束）：**
- 每期改动后需 bump 版本并更新静态资源 `?v=` 查询参数，避免公网缓存旧样式；
- 本项目是生产系统（极空间 NPM → Ubuntu FastAPI），样式变更不涉及数据库与聚合逻辑，走常规 `REBUILD_DATABASE=0` 发布即可；
- 验收需覆盖公网 HTTPS 入口的页面静态资源检查。
