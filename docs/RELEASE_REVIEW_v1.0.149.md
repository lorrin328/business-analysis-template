## 失败原因与修复

- 2026-09-04凌晨1点自动研究因B2模块出现无同模块证据支持的`5.8%`而失败；11:35手工研究因M10模块出现无同模块证据支持的`9月`而失败。两次均已完成模型和来源调用，失败点是报告发布前的证据门禁，不是API鉴权、定时器或服务器资源。
- 原流程先校验模型草稿，再独立核验来源并以已核验原文对齐模块事实。事实对齐可能使判断、影响或变化信号中的数字和日期失去同模块证据锚点，而最终校验位于修复循环之外，因此无法在同一次任务内修正。
- 新流程在最终事实对齐后捕获完整校验错误，最多追加一次定向修复；修复结果重新经过草稿校验、来源核验、事实对齐和不低于9分的发布门禁。未降低证据等级、数字锚点、历史连续性或质量阈值。
- 内容门禁最终失败使用退出码2，systemd通过`RestartPreventExitStatus=2`停止确定性重试；网络、模型接口等基础设施异常仍使用退出码1按既有策略重试。定时检查启动前清理旧failed状态，页面将此类错误显示为“报告未通过发布门禁”。
