# 经营分析看板 · 界面优化与美化报告

> 范围：`经营分析模板.html` 主看板 + 7 个子页面（职拓/网点/客户/荣誉/市场/人员/税优）
> 日期：2026-09-11 · 基于当前工作区代码实际审查

---

## 一、结论摘要

当前界面**功能完整、信息架构清晰**，深色金融终端风格方向是对的；主要问题不在"丑"，而在**一致性失控**：

1. **8 个页面 5 套色板**——主页面用 Tailwind slate 系（`#0f172a/#3b82f6`），荣誉页用 `#091426/#4f8cff/#25c285`，市场页 `#08111f`，人员页 `#0b1220`，税优页青绿渐变，字体栈也不统一。
2. **色彩语义混乱**——9 张 KPI 卡的大数字各配一种颜色（紫/粉/青/橙/蓝青……），颜色不承担含义，纯装饰，形成"彩虹看板"。
3. **细节工艺参差**——上传区用 emoji 图标、按钮/圆角/间距无统一标尺、ECharts 调色板与页面令牌脱节。

**建议路线**：不重写结构，分三阶段推进——先收口设计令牌（P0），再翻新主看板视觉（P1），最后把子页面逐一并入同一体系（P2）。预计 P0+P1 即可带来 80% 的观感提升，且风险低、可灰度回滚。

## 四、美化设计方向

目标气质：**"保险指挥舱"（Mission Control）**——保持深色金融终端基调，但从"默认深色模板"升级为"有纪律的专业看板"。核心是三件事：**颜色收口、数字立起来、控件成体系**。

### 4.1 设计令牌统一（全站一套 `:root`）

```css
:root {
  /* 背景：近黑深海军蓝，三层递进 */
  --bg: #0a0f1c;            /* 页面底 */
  --panel: #111a2b;         /* 卡片 */
  --panel-raise: #18243a;   /* 悬浮/输入 */
  --line: #1e2c46;          /* 1px hairline 分隔 */

  /* 文字：靠明度阶梯，不靠颜色 */
  --text: #eef3fb;
  --text-2: #93a4bd;        /* 次级 */
  --text-3: #5c6b84;        /* 弱化 */

  /* 唯一主色 + 语义色纪律 */
  --accent: #4f8cff;        /* 交互/选中 */
  --live: #22d3ee;          /* 实时/活跃 */
  --up: #34d399;            /* 正向 */
  --warn: #fbbf24;          /* 警示 */
  --down: #f87171;          /* 风险 */

  /* 标尺 */
  --r-sm: 6px; --r-md: 10px; --r-pill: 999px;
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px; --sp-6: 24px;
  --t-fast: .15s ease;
}
```

子页面全部改为引用同一份令牌（抽取为 `css/tokens.css` 或共享 `<style>` 片段），渐变背景收敛为"主色微光"一种表达。

### 4.2 KPI 区重构（观感提升最大的一处）

- **数字不再着色**：所有 KPI 大数字统一 `--text` 高亮色；色彩只出现在语义位置——同比箭头（绿涨红降）、达成状态徽章、目标未配置警示（琥珀）。
- **网格改自适应**：`grid-template-columns: repeat(auto-fit, minmax(150px, 1fr))`，9 张卡任何宽度下都整齐满排，不再出现 7+2、4+4+1 的残缺行。
- **卡片工艺**：去掉"上浮+顶部色条"，改为 1px hairline 边框 + hover 时左边框 3px 主色光条（克制的反馈）；加 `font-variant-numeric: tabular-nums` 全站统一（当前仅部分使用）。
- **标签体系**：顶部指标名用 12px / 字距放宽 / 次级色，数字 30px / 700 / tabular，底部同比行 11px——层级全靠字号字重，不靠颜色。

### 4.3 控件体系

- 页面内所有筛选按钮统一为**分段控件（segmented pill）**：圆角 999px、选中态实心主色+白字、未选中透明+hairline 边框；`.chart-btn`、`.org-dim-btn`、时间维度按钮合并为一套。
- checkbox 组保留但统一视觉：圆角 6px 标签样式 + `accent-color` 已具备，补齐统一 padding/行高。
- 上传区 emoji → 极简 inline SVG（线性、1.5px 描边、单色 `--text-2`），选中文件状态用左边框绿色光条 + 文件名等宽字体呈现。

### 4.4 图表联动

注册一个 ECharts 主题（如 `tpl-dark`），调色板从 CSS 变量读取：`[--accent, --live, --up, --warn, #a78bfa, --down]`，坐标轴/分割线用 `--line`，文字用 `--text-2`。JS 里 6 处写死的调色板全部替换为主题引用。

### 4.5 微交互与状态（P2）

- 所有可交互元素统一 `--t-fast: .15s ease`；补 `@media (prefers-reduced-motion: reduce)`。
- 表格/卡片加载态改骨架屏（`pulse` 动画的色块），空态用虚线边框容器 + 提示文案。
- 数据新鲜度：header 统计范围旁加"活体"指示（小圆点 1.5s 呼吸动画），暗示数据口径时间——与 `dataCutoff` 控件天然呼应。

## 五、实施路线

| 阶段 | 内容 | 改动面 | 风险 |
|---|---|---|---|
| **P0 修复** | 补 `--text-primary` 变量；清理 `.sync-conflict-*` 文件（先移入 `_external_materials/` 隔离，确认无引用后删除） | 2 处 | 极低 |
| **P1 主页翻新** | 抽 `css/tokens.css`；KPI 网格与卡片重做；控件统一；ECharts 主题；上传区 SVG 化 | 主页面 + `js/` 中配色引用 | 低（纯表现层，不动数据逻辑） |
| **P2 子页面并入** | 7 个子页面逐页替换变量与控件类，统一 header 形态 | 7 个 HTML | 低，可分批上线 |
| **P3 体验增强** | 骨架屏、reduced-motion、活体指示 | 全站 | 低 |

**验收方式**：每阶段完成后本地启动 FastAPI 对照截图走查（首屏 / KPI 弹窗 / 上传流程 / 一个子页面），确认无功能回归；部署仍走 `deploy.sh` 既有流程，样式变更不触碰数据库与迁移。

**不做的事**：不引入前端框架、不改 API、不动权限显隐逻辑、不改 ECharts 版本——本次纯表现层优化。
