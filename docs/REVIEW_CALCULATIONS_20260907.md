# 计算逻辑与展示字段复核（2026-09-07）

## 结论与范围

本轮发现4项可复现问题：产品件数缺失被保费替代、件数单位错误、产品结构截断导致占比分母缩小、经代10年交日级来源判断不完整。既有核心计算与筛选测试138项通过，说明现有常规路径有覆盖，但这些边界未被现有用例阻断。

本报告为代码只读复核，未读取生产数据库、客户行级数据或秘密；只创建系统临时目录中的合成测试库。本轮不认定这些条件已经出现在生产数据中，不修改经营口径或生产聚合。基线依据当前代码、AGENTS.md及docs/ai-context中的PROJECT_CONTEXT、DATA_DICTIONARY、DECISIONS、OPEN_QUESTIONS；历史文档不覆盖当前实现。

## 可复现问题

### F1 [P1] 产品件数缺失时以保费替代，产生虚构件数

- 位置：`js/data-integration.js:550`。
- 触发：产品接口返回非空`premium`，但`count=[]`或未提供件数。例如净承保件数为0而存在保费调整，后端过滤0件后可形成此响应。
- 当前行为：`productData.count = ... ? product.count : product.premium`将金额直接填入件数序列。
- 合成复现：执行实际`updateProductDataFromApi`函数，输入`premium=[{name:'合成产品',value:12.5}], count=[]`，结果`count=[{name:'合成产品',value:12.5}]`。
- 影响：切换“件数”后显示12.5并按金额结构计算占比，无法代表承保件数；金额与件数不是可互换字段。
- 修复动作：件数为空保留空数组，展示件数不可用；补充“保费非零、件数0/缺失”的前端回归用例。不要补0或以金额兜底。

### F2 [P2] 产品件数图仍使用金额单位“万”

- 位置：`js/product-analysis.js:19`；入口`经营分析模板.html:1620`。
- 触发：点击产品结构“件数”，悬停任意扇区。
- 当前行为：`getPieOption(type)`无论`type`为何，tooltip均为`{b}: {c}万 ({d}%)`。
- 影响：10件被显示为“10万”，单位与真实字段不一致。
- 修复动作：保费展示“万元”，转型件数展示“件”；经代计数字段当前实为源记录行数，应单独披露或关闭其承保件数视图，不能宣称为权威件数。经代件数来源限制已在DATA_DICTIONARY及OPEN_QUESTIONS说明，页面尚未充分体现。

### F3 [P2] 产品结构超过20类时占比分母被静默缩小

- 位置：`backend/db/repositories/product.py:132`（聚合路径）及`:299`（原始表回退路径）；`js/product-analysis.js:19`使用ECharts自动百分比。
- 触发：筛选范围出现21个及以上产品类别；经代按产品名称分组，容易达到此条件。
- 合成复现：临时库写入21个经代产品，各10万元。调用`_query_product_daily_aggregate`仅返回20项，合计200万元，源表合计210万元。
- 影响：图中每项占比显示5%，真实占总保费为4.76%；被截掉的产品无“其他”提示，不能与整体保费勾稽。件数序列也按保费排名截断，进一步遗漏低保费高件数产品。
- 修复动作：返回全量结构，或保留前N项并将剩余净额/件数汇入“其他”；占比分母须来自当前筛选全量数据。净负保费时应另行定义图示，不把有符号净额直接解释为普通饼图份额。

### F4 [P2] 经代10年交日表可用性误用其他业务记录

- 位置：`backend/db/repositories/kpi.py:369`至`:372`，并影响`:464`精度标记。
- 触发：期交转型/经代日表均可用，但`agg_payment_period_daily`只有转型记录，经代交期只存在于月表。
- 合成复现：2026年6月转型日保费100万元、经代日保费50万元；经代月交期“10年及以上”50万元；日交期仅转型“5年交”100万元。查询截至6月30日的KPI返回`tenyear_jd=0`，且`tenyear_jingdai_precision='day'`。
- 原因：可用性只查询`WHERE year=?`，没有判断经代来源覆盖；随后查询经代日表空集并强制转0，未走已设计的月级回退/告警。
- 影响：10年期整体、经代实绩和达成率被低估，精度标签错误地声称日级。
- 修复动作：按业务来源及实际查询范围核验聚合可用性；已知缺少经代日来源时保留月级回退与明确截止提示，无法判断来源完整时返回不可用。应覆盖“只有另一业务日记录”的回归场景。
