# v1.0.136 发布说明

## 星钻结果状态与外勤岗位分类

本版本在保留 v1.0.130—v1.0.135 市场研判与部署优化的基础上，补充星钻月份数据版本治理，并从底层区分专员与外勤管理职。

### 月末快照与最终结果分开

- 月内截至日显示为“过程数据”。
- 月末最后一天显示为“月末快照”，代表整月业绩已覆盖，但仍可能随回销状态变化。
- 月末之后的截至日显示为“回销观察更新”。
- 留空截至日只用于“最终结果”，最早在月末加45天后生成。
- 月份结束但缺少月末快照时，有权限用户可在页面直接生成。
- 查看月份仍然只读取已有结果，不会自动重算或改写数据。

以2026年7月为例：月末快照日期为2026年7月31日；45天观察期于2026年9月14日结束，因此7月31日版本是完整月业绩快照，不是最终结果。

### 专员与外勤管理职分开

- 底层新增 `staff_category`，值域为“专员”“外勤管理职”。
- 原 `role_type` 继续表示个人、主管、经理荣誉身份轨道，不再兼任人员岗位类别。
- 管理职人员的个人轨道仍按个人规则计算，但专员历史、机构会员结构和人员统计按 `staff_category` 分类。
- 存量批次按同批次、同年月、同人员、同业务线的人力源记录回填岗位类别，不改写历史钻石余额和会员等级。

### 发布与生产验收

- 2026年8月17日经 PR #12 合并到 GitHub `master`，Docker 镜像构建成功。
- 生产采用可信发布包和保库快速路径发布，未使用旧 Excel 重建数据库，未触发聚合重建。
- 部署前完成约5GB SQLite 在线一致性备份，52张表的 `integrity_check` 与 `quick_check` 均为 `ok`；部署前后核心业务表行数一致。
- 生产最新成功星钻批次当前会员59人：专员51人、外勤管理职8人；荣誉身份轨道为个人53人、主管5人、经理1人，岗位类别与身份轨道已实现独立统计。
- 生产健康检查、首页、星钻页和前端脚本均正常，应用与页面版本均为 `v1.0.136`。
