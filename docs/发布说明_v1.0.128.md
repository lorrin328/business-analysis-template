# v1.0.128 发布说明：市场研判格式自校准与坏源安全降级

## 修复内容

- 来源分类计数和页面字段长度改由程序确定性校准，避免纯格式问题触发长时间模型修复。
- 修复检查点先复用既有研究并完成本地归并，不再因可计算字段重新执行整轮研究。
- 独立验证失败来源仅在全部引用仍满足证据数量和等级门槛时安全剔除；唯一或关键证据继续阻止发布。

## 安全边界

- 宏观和监管模块剔除失败来源后仍须保留官方 A 级证据。
- 同业模块剔除失败来源后仍须保留公司、协会、官方微信或政府的一手 A/B 级证据。
- 报告总来源不得少于 8 项，任何引用项不得失去全部证据。
- TLS证书链不得通过关闭校验或忽略错误绕过。

## 验收重点

- 生产修复检查点可在不重新执行完整研究的情况下完成格式归并和安全坏源处理。
- 剩余来源必须逐项通过HTTP状态、最终URL、标题、发布日期、正文摘录和内容哈希验证。
- 每个模块仍须恰好映射一条同状态变化信号，失败报告不得覆盖上一期有效报告。
